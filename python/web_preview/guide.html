SPLINED WebUI guide

Return to workspace

This local browser build is a read-only artwork workspace preview. It can inspect the isolated index, search Fanart.tv and Deezer for artist images, and preview adjustments. It does not write images, database rows, or audio tags.

Find artwork

  1. Select an artist in Media Library. Albums appear inside Artist Overview. Select an album for its cover. Prior candidates clear as soon as focus changes.
  2. Press LAUNCH to search connected artist image sources. The colored status bar reports progress and results. Local artist and album images are available without an online search.
  3. Use the blue control on a candidate to preview it as the artist image and the pink control for its banner. Click the small outlined control beside the overview artist thumbnail to enter Artist Art from an album. Pressing Artist Art clears the previous candidate strip before the new search.

Enhance a preview

Open Artists Art Enhancements or Album Art Enhancements. In Artist Art, the current package stays in pane 1; pane 2 previews an artist image and pane 3 previews a banner. The pane radios choose what appears in Selected Artwork. Both proposed radios show a package; Themed Packaging appears inside the upper left of Selected Artwork to allow package-wide preview adjustments.

The Filters, Fitment, and Detailed menus adjust the browser preview only. Drag their sliders with the mouse. Wheel over an artist or banner preview to zoom; drag to position. Double-click a slider to reset it. The small reset beside Enhancements clears the active preview adjustments.

Album Track Embedding

EMBED Batch places the selected album in a temporary browser queue. Opening Album Track Embedding alone does not stage anything. The queue can be cleared; embedding audio files is not connected in this build.

Overview metadata

Album names, track counts, status, and album tracks come from the isolated music index. Artist biographies, similar artists, and top songs are requested from Navidrome when credentials and metadata are available. When Navidrome does not supply them, the overview says so and marks the similar-artist layout as a sample. Songs from the local index are labelled Indexed songs, since they are not popularity ranked. Navidrome metadata depends on its configured integrations.

Current test limits

WRITE Artist Art, WRITE Cover, actual upscaling, tag embedding, MusicBrainz review, and the other Windows image providers are not connected. Settings shows the current read-only paths. The dedicated PostgreSQL container is planned for the service version; this local build still reads an isolated SQLite index.
